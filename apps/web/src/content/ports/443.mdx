Port `443` is the default encrypted web port. It is one of the most common public checks because so many APIs and sites terminate TLS there.

## Common uses

- Secure websites
- Public APIs
- Reverse proxies and CDNs

## Important nuance

A TCP `open` result on `443` only proves the socket answered. It does not prove your certificate, origin routing, or application response is healthy.
