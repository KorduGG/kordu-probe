Port `3389` is usually associated with Microsoft Remote Desktop. Public exposure is common in smaller setups and strongly discouraged in many production environments.

## Common uses

- Windows administration
- Jump hosts
- Ad hoc support access

## Security note

An `open` result on `3389` is a visibility answer, not a recommendation. Many teams intentionally move RDP behind VPNs, Zero Trust access, or jump hosts.
